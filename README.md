# EventEaseFinal

EventEaseFinal is an ASP.NET Core MVC web application for managing venues, events, and bookings.

## Features

- Venue CRUD functionality
- Event CRUD functionality
- Booking creation
- Event type lookup table
- Venue availability tracking
- Advanced booking filters
- Search by event name, venue name, or booking ID
- Date range filtering
- Double-booking prevention
- Venue and event deletion restrictions
- SQL View for consolidated booking information
- Azure SQL Database integration
- Azure App Service deployment
